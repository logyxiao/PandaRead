## 设置浮层与单双栏体验统一计划

### 1. 设置弹窗改为按钮左侧浮层
- 在 `App.tsx` 用统一 `openSettings(event)` 获取点击按钮的 `getBoundingClientRect()`。
- `FolderTabs`、首页设置按钮、单栏工具条、双栏工具条统一传递按钮点击事件。
- 移除 `.modal-backdrop/.settings-backdrop` 的遮罩用法；新增固定定位的 `settings-flyout`：
  - 默认出现在设置按钮左侧，保持 10px 间距。
  - 宽度约 360px，最大高度约 560px；上下位置按窗口边界自动夹紧。
  - 首页左侧按钮空间不足时自动翻到按钮右侧。
  - 点击浮层外、按 Esc、点关闭或取消均关闭。
- 面板改为更紧凑的两列布局，去掉大标题区和大尺寸圆形关闭按钮，避免遮挡阅读内容。

### 2. 设置实时预览与取消回滚
- 打开面板时记录原始 `settings` 和当前单双栏模式快照。
- 面板中主题、亮度、字体、字号、页面宽度、阅读模式、行距、页边距改变时，立即写入 App/Zustand 临时状态，阅读框实时变化，不写数据库。
- 「应用」才调用 `api.saveSettings`、更新窗口置顶并持久化。
- 「取消」/关闭/点击外部/Esc 恢复打开面板时的设置与单双栏模式，避免临时预览残留。
- 保留现有配置 JSON 兼容，不修改已保存的其他偏好。

### 3. 重做可用的亮度控制
- 亮度改为 40%–100% 的阅读区调暗控制；不再提供近白背景上无实际效果的 100%–140% 区间。
- 滑块使用清晰的亮暗图标、已填充轨道、当前百分比和一键恢复 100%。
- 不再对 `.paper/.page-paper` 使用 `filter:brightness()`；改为在 `.reader-pane` 上添加 `pointer-events:none` 的半透明黑色覆盖层，透明度由 CSS 变量计算：
  - 单栏和双栏整块阅读区域都能明显变暗。
  - 工具条和设置浮层保持正常亮度、仍可操作。
  - 日间、护眼、羊皮纸、夜间主题都能稳定感知变化。
- 拖动滑块即时更新覆盖层，解决当前亮度“拖了没反应”的问题。

### 4. 单双栏共用阅读工具条
- 抽出一个共享 `ReaderToolbar`，替代 `PagedReader` 的 `page-floating-tools` 和 `SingleReader` 的 `ReaderFloatingTools` 两套实现。
- 两种模式统一按钮顺序、尺寸、圆形样式、tooltip、`aria-pressed`：
  1. 目录
  2. 排版
  3. 单栏/双栏切换
  4. 收藏
  5. 夜间
  6. 素材
  7. 标签
  8. 设置
  9. 编辑（可编辑文档）
- 双栏补齐目录功能：点击章节按章节 offset 映射到对应页。
- 双栏点击「编辑」时切到单栏并直接进入编辑；为此把 `editMode` 从 `SingleReader` 提升到 App 层，单双栏共享同一编辑状态。
- 目录弹层也由共享工具条组件维护，位置跟随统一工具条。
- 清理重复/失效的 `.page-floating-tools` 与旧 `.reader-floating-tools` CSS，统一移动端尺寸、右侧间距、短窗口滚动可达性。

### 5. 阅读表面一致性
- 双栏补齐文稿标题和可复制路径标题区，与单栏一致。
- 双栏正文使用 `--reader-font`，修复当前字体设置仅对单栏生效的问题。
- 统一单栏/双栏距右侧工具条的留白和夜间样式；仅保留必要差异：单栏滚动、双栏分页和页码控制。
- 保留现有快捷键：左右翻页/翻屏、PgUp/PgDn 切文件、单栏上下逐行滚动。

### 6. 验证
- `npx tsc --noEmit`
- `npm run build:web-only`
- `cargo check` 与现有 Rust 测试（ReaderSettings 反序列化兼容）
- 按用户默认由用户自行实测：浮层定位、实时主题/字号/宽度/亮度预览、取消回滚、单双栏工具条一致、双栏目录与编辑切换。
